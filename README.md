# 해운대구 예산서재

첨부된 겹친 카드 디자인을 참고한 개인용 해운대구 예산 자료 관리·비교 프로그램입니다. 실제 예산 수치 또는 자동 분석 결과는 포함되어 있지 않습니다.

## 실행

Node.js 18 이상에서 이 폴더의 터미널을 열고 `npm start`를 실행한 뒤 http://127.0.0.1:4173 에 접속합니다. 패키지 설치는 필요하지 않습니다. 종료하려면 Ctrl+C를 누릅니다. 주소와 브라우저 프로필을 일정하게 유지하십시오. 파일을 직접 더블클릭하는 방식은 브라우저별 저장소 동작이 달라 권장하지 않습니다.

## 사용

1. 기준연도를 선택합니다. 2026을 선택하면 2024·2025·2026 자료를 표시합니다. 다른 연도의 자료도 저장되며 기준연도 변경으로 조회합니다.
2. 본예산·추경예산·결산·사업명세서·기금·검토보고서 폴더에 자료를 등록합니다. 추경 차수는 자료명에 기입합니다. 기금운용계획·변경계획·기금결산은 기금 폴더에서 자료명으로 구분합니다.
3. 사업 수치를 천원 단위로 입력합니다. 동일 사업에는 같은 사업코드·부서·회계명을 사용합니다. 명칭이나 소속이 변경되면 동일 사업 여부를 원문으로 확인한 후 식별정보를 정리하십시오. 자동으로 동일 사업을 판단하지 않습니다.
4. 근거 자료와 쪽수를 연결합니다. 금액별 근거가 서로 다른 경우 쪽수/표·항목 또는 메모에 각각의 자료명·쪽수를 명시하십시오. 현재 연결 자료는 연도별 기록당 하나입니다.
5. 연도별 버튼으로 입력값과 근거를 확인하거나 수정합니다. 미입력은 결측으로 표시하고, 분모가 0인 증감률·집행률은 계산하지 않습니다. 지출액/최종예산 집행률은 전년도 이월 등을 포함한 예산현액 기준 공식 집행률과 다를 수 있습니다.
6. 전체 백업을 정기적으로 저장합니다. 첨부 파일을 포함한 JSON 백업입니다. 복원하면 현재 자료가 전체 교체됩니다.

## 개인용 구조와 한계

- 서버는 127.0.0.1에서만 접속을 받습니다. 외부 서버 전송, 원격 분석 서비스, 추적 코드, 외부 폰트가 없습니다.
- 자료와 파일은 브라우저 IndexedDB에 보관됩니다. 브라우저 데이터 삭제·프로필 변경·주소 변경·기기 변경으로 접근이 끊길 수 있습니다. 장기 보관은 원문 별도 보관과 백업이 필요합니다.
- 로그인·사용자 인증·저장 암호화는 구현되지 않았습니다. 이 컴퓨터와 브라우저 프로필을 사용할 수 있는 다른 사람은 접근할 수 있습니다. 백업도 암호화되지 않습니다.
- PDF/HWP 원문을 자동 추출하거나 분석하지 않습니다. PDF는 브라우저에서 열고 HWP/HWPX 등은 내려받아 적합한 프로그램에서 열 수 있습니다. 수치를 직접 검증해 입력해야 합니다.
- 최종예산·지출액·이월액·집행잔액의 회계상 관계, 단위, 국·시비 변화, 신규·종료 사업 여부를 자동으로 법적·회계적으로 판단하지 않습니다. 증감률 자체가 문제사업 또는 위법의 근거는 아닙니다.
- 백업은 파일 전체를 메모리에 올리므로 매우 큰 자료묶음은 브라우저 메모리 제한에 영향을 받을 수 있습니다. 원문 파일은 별도 보관하십시오.

## GitHub 보관

Private 저장소를 생성하고 이 폴더의 프로그램 파일만 올리십시오. 백업·실제 원문 자료·비밀번호는 올리지 마십시오. `.gitignore`는 기본 이름의 백업과 private-data 폴더를 제외하지만 파일 이름을 바꾸면 보호되지 않습니다. 업로드 전 직접 확인하십시오.

이 버전은 로컬 개인용 실행을 기본으로 합니다. GitHub 저장소의 비공개 설정만으로 배포된 웹사이트의 접근 통제를 보장할 수 없습니다. 외부 배포가 필요하다면 배포 서비스의 접근 통제와 본인 인증을 별도로 구현·검증해야 합니다. 이번 작업에서는 GitHub 업로드 또는 외부 배포를 수행하지 않았습니다.

## 검증

`npm run check`: JavaScript 구문 검사. 브라우저에서 자료 등록→파일 열기→사업 입력→기준연도 변경→백업→복원을 확인하십시오.

## 출처

화면 디자인: 사용자 제공 참고 이미지(2026). 겹친 카드·청색 표지·민트 및 분홍색 후면 색상을 참고하였습니다. 외부 예산자료나 논문은 사용하지 않았습니다. 계산식은 이 프로그램의 비교 규칙이며 공식 재정지표로 인증된 값이 아닙니다.
